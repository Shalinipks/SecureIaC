# SecureIaC

## Securing AI-Generated Cloud Infrastructure with Automated IaC Security Guardrails

SecureIaC is a security framework designed to detect security vulnerabilities and misconfigurations in AI-generated Infrastructure as Code (IaC) before cloud deployment.

### Technologies

- Python
- Terraform
- GitHub Actions
- Checkov
- TFLintt 
- Gitleaks
- AWS

### Objective

To automatically scan AI-generated Terraform code, identify security issues, and prevent insecure infrastructure from being deployed to the cloud.
